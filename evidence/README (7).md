# Evidence collection — Domain 5 / Red Hat 1

This directory intentionally contains **no screenshots**. Two screenshots from Lab 03 were saved locally by the learner but were not supplied here for public distribution.

## How to add evidence

1. Redact passwords, auth tokens, private URLs, account IDs, personal addresses and other secrets.
2. Prefer evidence that shows the command and the output in one view.
3. Give images clear names, such as `lab-03-nginx-bind-mount.png`.
4. After uploading images here, link them from the relevant lab README and progress JSON's `evidenceUrl` (only if that URL is real).
5. Never generate or fabricate terminal output/screenshots as proof.

Future labs: capture screenshots before the ephemeral practice environment expires.
