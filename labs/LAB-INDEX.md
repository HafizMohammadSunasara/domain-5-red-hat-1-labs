### Topic 02 — engineering learning map

| Lab | Main engineering question | Takeaway |
|---|---|---|
| **01 — FROM** | Which base image should start the build? | Image selection, image tags, version pinning and reproducibility |
| **02 — RUN** | How can build commands be structured efficiently? | Shell vs exec form, build layers, cache cleanup and measured image comparisons |
| **03 — ADD vs COPY** | When is ordinary copying safer than automatic extraction/downloads? | Build-context files, archives, remote sources, cache invalidation and security considerations |
| **04 — WORKDIR & USER** | How does a container obtain predictable paths and a limited identity? | Working directories, creating a non-root account, filesystem permissions and least privilege |
| **05 — Least Privilege** | How can an image and its runtime be hardened? | Vulnerability-scanning concepts, smaller base images, non-root Nginx and signing/provenance distinctions |
